The project was built with **Devin** (Cognition's autonomous coding agent) working in a VM with shell, Docker and GitHub access, driven by the assignment brief.

| Infra / CI | Dockerfile, compose, Prometheus rules, Grafana dashboard, GitHub Actions, Render blueprint | `docker compose up --wait` + smoke test script; `promtool check config/rules` |
| Docs | Drafted README / ARCHITECTURE / this file | Reviewed against the actual code and config |

## Issues caught during AI-assisted development (examples)

- `pydantic-settings` JSON-decodes `list[str]` env vars, so `CORS_ORIGINS=http://a,http://b` crashed the container at boot even though tests passed (tests never set it). Found by the Docker smoke test; fixed by keeping it a string and parsing explicitly, with a regression test.
- `email-validator` rejects reserved TLDs like `.test`; the smoke script was adjusted to `example.com`.
- mypy flagged a possible `None` comparison on a `COUNT(*)` scalar.
- Docker Hub rate-limited the build host, so images are pulled from the public ECR/quay mirrors.
- Frontend lint flagged `setState` inside effects; form resets were moved into mutation `onSuccess` callbacks.

## Principles followed

- AI output was treated as a draft: nothing merged without lint, type checks, tests and a running-system check.
- Correctness-critical code (money arithmetic, locking, idempotency) got tests written specifically to falsify it, including concurrency tests.
- No secrets were given to or generated into the repository; production secrets are generated by the platform (`generateValue` in `render.yaml`) or held in GitHub secrets.
